# Обзор обучающего датасета (ручной просмотр)

42 файла `.mov`, 464x848 (портрет), ~30 FPS, 11–143 с. 22 с нарушением, 20 без.
Дубликаты (md5 совпадает): `Х-4` = `Х-47` (метки 57 с и 68 с → в одном видео ≥2 нарушения),
`Х-5` = `Х-48` (оба без нарушения). Имена смешивают латинскую `X` и кириллическую `Х`.

Сцена: одна комната, камера сверху из угла, стол кассира, счётчик банкнот, ноутбук,
телефон, сейф (серый шкаф), стеклянная дверь слева сверху. Несколько вариантов
расстановки мебели/ракурса и освещения (Х-11 — свет гаснет).
