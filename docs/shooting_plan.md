# План доснятия видео (устойчивость к другому ракурсу)

Финальное тестовое видео будет снято под другим углом. FAQ разрешает дополнять датасет своими съёмками.

## Сцена

Стол, похожий на кассу: счётчик (или коробка вместо него), ноутбук, телефон, «сейф» (тумба или шкаф),
стул клиента напротив. Желательно, чтобы в кадр попадала дверь.

## Ракурсы

Каждый сценарий снимаем с 2–3 точек. Телефон на штативе, видео **вертикальное**, 30 FPS (как в датасете).

| Код | Ракурс |
|---|---|
| A | сверху из угла, как в датасете (контроль) |
| B | сверху, с противоположного угла (зеркальный ракурс) |
| C | сбоку на уровне ~2 м (камера смотрит вдоль стола) |
| D | почти прямо сверху (если есть возможность) |

## Сценарии (10–30 с каждый)

| № | type_id | Что делать | Ракурсы |
|---|---|---|---|
| 1 | `phone_use` | сидит за столом, берёт телефон и смотрит в него 5+ с | A, B, C |
| 2 | `food_drink` | пьёт кофе из кружки / ест печенье | A, B, C |
| 3 | `unattended_valuables` | кладёт пачку «денег» на стол и уходит из кадра | A, B, C |
| 4 | `unlocked_workstation` | работает в таблице и уходит, ноутбук открыт, приложение на экране | A, B, C |
| 5 | `personal_items` | ставит сумку / кладёт куртку на стол и работает | A, B |
| 6 | `door_left_open` | входит и садится, дверь остаётся открытой | A, B |
| 7 | `cash_left_in_client_zone` | «клиент» уходит, деньги на столе, входит следующий | A, B |
| 8 | `none` | уходит, перед этим блокирует экран (Win+L) — экран горит, но заблокирован | A, B, C |
| 9 | `none` | уходит, перед этим убирает деньги в «сейф» и закрывает ноутбук | A, B |
| 10 | `none` | обслуживание «клиента»: принять деньги, пересчитать на счётчике при нём | A, B |
| 11 | `none` | входит и закрывает за собой дверь, садится работать | A, B |

Сценарии 8–11 — **трудные отрицательные примеры**. На них ловим ложные срабатывания: они
повторяют позитивные сценарии, кроме одной детали.

## Разметка

Заполнить [extra_labels.csv](extra_labels.csv): одна строка на нарушение; для роликов без нарушений —
строка с пустым `time_sec` и `type_id=none`. Время — секунда **начала** нарушения (как у организаторов).

Имена файлов: `E-<№сценария>-<ракурс>-<дубль>.mov`, например `E-04-B-1.mov`.
Файлы класть в `data/extra/` (папка в `.gitignore`). **В git видео не коммитить.**
